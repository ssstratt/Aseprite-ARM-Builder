## Overview

This repository provides an automated GitHub Actions workflow configured to compile [Aseprite](https://github.com/aseprite/aseprite) from source for **ARM64 Linux distributions** (such as ARM-based Chromebooks running Crostini, Raspberry Pi, and other ARM Linux devices). 

Since official precompiled Skia binaries for ARM64 Linux do not exist, this workflow compiles both Google's Skia library and Aseprite from scratch using a specialized Clang toolchain and link-time optimizations.

## How to Build Aseprite

1. **Fork this repository** to your own GitHub account.
2. Go to the **Actions** tab of your forked repository.
3. Click on the **Build Aseprite for ARM Linux** workflow in the left sidebar.
4. Click the **Run workflow** dropdown menu on the right.
5. Enter any custom build notes (or keep the default) and click the green **Run workflow** button.

> ⏱️ **Build Time Note:** Compiling Skia and Aseprite from source on an ARM runner is resource-intensive and takes **approximately 25 minutes** to complete.

Once the workflow finishes successfully, go to the workflow run summary page and download your compiled artifact zip file from the **Artifacts** section.

## Installation & Setup (ChromeOS & Linux)

Once you have downloaded and moved your build zip file into your Linux environment (under your **Linux files** folder), follow these steps to set it up:

### 1. Extract the Application
Open your terminal and extract the downloaded archive directly into your home directory (the asterisk `*` automatically acts as a wildcard for any version numbers):

```bash
cd ~/
unzip Aseprite-*.zip -d ~/aseprite
```

### 2. Install Runtime Dependencies (If Needed)
Make sure your Linux environment has the required LLVM runtime libraries installed so the application can load properly:
```bash
sudo apt-get update && sudo apt-get install -y libc++1-18 libc++abi1-18
```

### 3. Create an App Launcher Shortcut
To make Aseprite show up cleanly in your ChromeOS app drawer or Linux application menu, copy and paste this command block into your terminal and press Enter:

```bash
mkdir -p ~/.local/share/applications
cat << EOF > ~/.local/share/applications/aseprite.desktop
[Desktop Entry]
Name=Aseprite
Comment=Animated sprite editor & pixel art tool
Exec=env GDK_BACKEND=x11 /home/$USER/aseprite/aseprite %U
Icon=/home/$USER/aseprite/data/icons/ase256.png
Terminal=false
Type=Application
Categories=Graphics;2DGraphics;RasterGraphics;
EOF
```

Give your system a brief moment to refresh, and Aseprite will be available right inside your app launcher!
